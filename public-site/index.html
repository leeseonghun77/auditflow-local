A AuditFlow
문제 솔루션 기능 보안

Local-first automation for club accounting audit

반복적인 회계감사 제출 작업을 파일 업로드 한 번으로 정리합니다.

은행 PDF 거래내역서, 엑셀 장부 양식, 영수증 사진을 로컬 웹앱에서 처리해 감사 제출용 엑셀과 지출증빙 PDF를 자동 생성하는 프로젝트입니다.

기능 보기 보안 설계
Input

Bank PDF · Excel template · Receipt images

→
Automation

Parsing · Matching · Evidence memo

→
Output

Filled workbook · Evidence PDF

Problem

감사 제출은 단순하지만, 사람이 하기엔 실수가 나기 쉽습니다.

동아리 회계감사에는 은행 발급 거래내역서, 엑셀 거래내역서, 지출증빙자료가 함께 필요합니다. 거래를 하나씩 옮기고 영수증을 번호별로 정리하는 과정은 반복적이고, 번호·날짜·금액이 어긋나기 쉽습니다.

Solution

공개 소개 페이지와 비공개 실행 도구를 분리했습니다.

Public

포트폴리오 소개 페이지

문제정의, 자동화 흐름, 기술스택, 보안 설계를 공개합니다. 실제 회계자료 업로드 기능은 포함하지 않습니다.

Private

로컬 실행 웹앱

민감한 PDF와 엑셀은 사용자의 PC에서만 처리합니다. 결과 파일을 내려받고, 원본 업로드 파일은 서버에 저장하지 않습니다.

Features

자동화 범위

01

거래내역 자동 입력

카카오뱅크·토스뱅크 PDF에서 날짜, 거래 상대, 입금, 출금, 잔액을 추출해 엑셀 양식에 채웁니다.

02

감사 비고 보완

지출증빙 PDF의 번호·항목명·날짜를 읽어 출금 거래와 연결하고, 제출 전 확인이 필요한 항목을 표시합니다.

03

지출증빙 PDF 생성

영수증 사진과 항목 정보를 입력하면 A4 세로 증빙자료 PDF를 자동으로 구성합니다.

04

검산용 보조 시트

원문 거래내역, 증빙 목록, 요약 시트를 함께 만들어 감사자가 빠르게 대조할 수 있게 합니다.

Security & Privacy

실제 자료는 공개 저장소에 올리지 않는 구조입니다.

  • 실제 PDF, XLSX, 영수증 이미지는 GitHub 제외 대상
  • 업로드 파일은 로컬 실행 중 임시 폴더에서만 처리
  • 공개 페이지는 기능 설명만 제공하고 파일 업로드 기능 제외
  • 민감 데이터 없는 코드와 문서만 포트폴리오로 공개
