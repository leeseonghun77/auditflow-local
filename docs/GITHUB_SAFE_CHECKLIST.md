# GitHub 공개 전 체크리스트

이 저장소는 포트폴리오 공개를 목표로 합니다. 실제 감사자료와 계좌정보는 절대 커밋하지 마세요.

## 올려도 되는 것

- Python 코드
- 로컬 웹앱 코드
- 공개 소개 페이지 코드
- README / 설명 문서
- 익명화된 샘플 데이터 설명

## 올리면 안 되는 것

- 실제 은행 거래내역서 PDF
- 실제 회계 엑셀 파일
- 실제 지출증빙 PDF
- 영수증 사진
- 계좌번호, 예금주, 전화번호, 학생 이름이 포함된 자료
- 생성된 결과 엑셀/PDF

## 커밋 전 확인 명령

```bash
git status --ignored
```

실수로 민감 파일이 추적되었다면, 파일은 지우지 말고 Git 추적에서만 제거하세요.

```bash
git rm --cached "파일명"
```

그 다음 다시 `git status`로 확인하세요.
